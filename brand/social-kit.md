## Medium

Medium shows the author's name on every story, so to stay separate from your personal name, create a **separate Medium account** for the brand:

1. Sign up at medium.com with **hello@cracktech.app**.
2. **Name:** Crack Tech
3. **Profile photo:** `crack-tech-avatar-400.png`
4. **Short bio** (max 160 characters):
   > Private 1:1 tech interview coaching. Coding, code with AI, system design, agentic AI and behavioral. Free intro call: cracktech.app
5. **About page** (Settings → Profile → About): reuse the LinkedIn overview above.
6. Optional later: a **publication** called "Crack Tech" (Profile → Publications → New publication), using the avatar as the publication avatar and `crack-tech-logo-for-light-backgrounds.png` as the logo.
