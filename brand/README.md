# Crack Tech brand assets

The Crack Tech mark is an olive rounded square with `</>` chevrons, taken from the website's logo and favicon.

| File | Use it for |
|---|---|
| `crack-tech-avatar-1024.png`, `crack-tech-avatar-400.png` | Profile pictures that get cropped into a circle: Cal.com, WhatsApp Business, Google, LinkedIn |
| `crack-tech-avatar.svg` | The avatar as a vector |
| `crack-tech-icon-1024.png`, `-512.png`, `-180.png` | The rounded-square icon on a transparent background (180px is for phone home-screen icons) |
| `crack-tech-icon.svg` | The icon as a vector, for print or design tools |
| `crack-tech-logo-for-light-backgrounds.png` | Icon + "Crack Tech" wordmark in dark text |
| `crack-tech-logo-for-dark-backgrounds.png` | Icon + "Crack Tech" wordmark in light text |

## Brand

- Olive: `#4f5d2a`
- Ivory: `#f6f3ec`
- Dark background: `#13150e`
- Wordmark font: Instrument Serif. Body font: Geist.
